# 五人小樣本腳本（尚未跑）

這份腳本只準備給人類執行。跑完之前，產品不得宣稱學習成效、不得宣稱「能讓人講出因果」已成立。

本檔不含通過紀錄。填結果時另開人類具名紀錄，不要改寫本檔把「尚未跑」改成「已通過」。

## 通過線（預先寫死）

請 **5** 位沒維護過本倉的人，各自單獨走一次，限時約 **8 分鐘**。

**通過**：至少 **4 / 5** 人在不被提示「正確答案」的情況下，能用自己的話說出這類因果：

> 我把肺端供氧拉低（或把貧血拉高），肺泡那邊的氧或平均負載變少了；沒有改條件的那一側沒有這樣掉。

不要求說出 load、stock、tick、A/B 等術語。講反了、講成臨床診斷、或講不出「我改了什麼 → 哪裡變了」都算未過。

## 主持人只准說的話

開場只念下面這段，然後閉嘴看：

1. 打開網址（本機 `http://127.0.0.1:8642/` 或 `loop.html`）。
2. 按「跟著一顆紅血球」，看它走一圈。
3. 自己改一個條件。
4. 看兩邊差在哪，用一句話說「你改了什麼、什麼變了」。

禁止：指滑桿、解釋 A/B、糾正用詞、提示該看哪一條水位。對方卡住超過兩分鐘，記「未完成」，不要教完再算通過。
